# 🏛️ WinoxIT — Kamu Özel Yazılım Dağıtım Paketi
## UYAP, e-İmza (AKİS / TÜBİTAK UEKAE), DYS ve Sertifika Deposu

Bu dizin, kamu kurumları (Adalet Bakanlığı, BTK, Bakanlıklar, Valilikler vb.) için yerel LAN önbelleği ve çevrimdışı kurulum havuzudur.

### 📦 Desteklenen Paketler:
1. **UYAP Editör:** Adalet Bakanlığı Ulusal Yargı Ağı Bilişim Sistemi UYAP Doküman Editörü.
2. **AKİS Akıllı Kart:** KamuSM TÜBİTAK Akıllı Kart Sürücüsü (ACS, Gemalto, Omnikey kart okuyucuları).
3. **Java Runtime (JRE / OpenJDK):** Kamu web uygulamaları için 64-Bit Java çalışma ortamı.
4. **Kamu Kök Sertifikaları:** TÜBİTAK Kamu Sertifikasyon Merkezi Kök Sertifikaları (Yerel Windows Sertifika Deposu `Root` otomatik yükleme).
